Ancore Proteção Veicular — Site Institucional

Este site é um template estático HTML5:
Não há integração com CMS (WordPress, Joomla, etc.). Todo o conteúdo é editado diretamente nos arquivos HTML, CSS e JS do projeto.

Sobre o Projeto

Site institucional da Ancore, construído com HTML5, Bootstrap 5 e JavaScript, usando AOS (animações de scroll), Slick Slider (carrosséis) e Fancybox (lightbox/vídeos) sobre jQuery.

Desenvolvido por Giovanni Marcaccini (Front-end & Web Design).

Como editar o Título e Favicon?

Abra index.html (ou a página desejada) e edite as tags no <head>.

Caminho: ancore_site > html_template > index.html

<title>Ancore</title>
<link rel="icon" href="favicon.ico" type="image/x-icon">
Atenção: a alteração feita em uma página vale apenas para ela. Para mudar título/favicon no site inteiro, é preciso editar cada arquivo HTML.

Como editar a Logo?

A logo é referenciada em todas as páginas, no cabeçalho (navbar) e no rodapé.

Caminho da imagem: ancore_site > html_template > images > ancore > logo-menu.svg

<a class="navbar-brand" href="index.html">
  <img src="images/ancore/logo-menu_branca.svg" alt="Main Logo" class="img-fluid">
</a>
Atenção: a alteração feita em uma página vale apenas para ela. Para trocar a logo no site inteiro, é preciso editar cada arquivo HTML (ou substituir o próprio arquivo logo-menu.svg).

Como editar o Rodapé?

O rodapé (logo, redes sociais, menu, contato e certificações) fica no final de cada página.

Caminho: ancore_site > html_template > index.html (tag <footer class="footer">)

<h4>Menu</h4>
<ul>
  <li><a href="#">Início</a></li>
  <li><a href="#">Seja associado</a></li>
  <li><a href="#">Sobre Nós</a></li>
  ...
</ul>
Atenção: o rodapé é repetido em todas as páginas HTML. Alterar um link ou texto exige editar o mesmo trecho em cada arquivo.

Como editar as Cores?

As cores do site são controladas por variáveis CSS (custom properties) no topo do arquivo de estilos.

Caminho: ancore_site > html_template > css > style.css

:root {
  --primary-color: #DF3B34;
  --secondary-color: #1E1F23;
  --text-color: #EEEEEE;
  --accent-color: #FF7B6E;
  --heading-color: #FFFFFF;
  --divider-color: #2A2B30;
  --background-alt-color: #25262B;
  --placeholder-color: #808080;
  --black-color: #000000;
  --font: "Barlow", sans-serif;
}

Third Party Plugins Activation

Name Plugins Activation Code
Animation On Scroll (AOS) 
$(document).ready(function () {
  // Initialize AOS (Animate On Scroll)
  AOS.init({
    duration: 800,
    once: true
  });
});
Fancybox JS Lightbox 
$(document).ready(function () {
  // Fancy Box
  Fancybox.bind("[data-fancybox]", {
    Carousel: {
      Video: {
        autoplay: true,
      },
    },
  });
});
Slick Slider 
$(document).ready(function () {
  // Client Logo
  $('.client-logos').slick({
    slidesToShow: 3,
    slidesToScroll: 1,
    centerMode: true,
    centerPadding: '120px',
    autoplay: true,
    autoplaySpeed: 1500,
    arrows: false,
    dots: false,
    pauseOnHover: false,
    responsive: [{
      breakpoint: 768,
      settings: { slidesToShow: 2 }
    }, {
      breakpoint: 520,
      settings: { slidesToShow: 1 }
    }]
  });

  // Testimonial
  $('.testimonial-slide').slick({
    slidesToShow: 3,
    slidesToScroll: 3,
    autoplay: true,
    dots: true,
    arrows: false,
    autoplaySpeed: 2000,
    responsive: [{
      breakpoint: 768,
      settings: { slidesToShow: 2, slidesToScroll: 1 }
    }, {
      breakpoint: 520,
      settings: { slidesToShow: 1, slidesToScroll: 1 }
    }]
  });
});
